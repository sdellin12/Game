# Model and context workflow

Steve prefers one Sol coding agent for routine implementation, tests, UI and docs.
Use scoped deeper reasoning for architecture/timing audits when needed; do not
spawn agents by default or promise an automatic model switch or usage allowance.
Current session/user instructions govern available tools and execution choices.

Read PROJECT_STATE.md, then the single relevant source/spec. Expand for concrete
dependencies; use DOCUMENTATION_INDEX.md when a broader audit is requested.
Do not read the interview archives or generated card outputs by default. Edit
report/template generators and regenerate their outputs. Keep rules in canonical
owners instead of copying them into every status note.

Run bulk games and checks in local code. Give the AI compact metrics and selected
outlier traces, not full game logs. Ask at most two or three batched questions when
blocked. Routine reversible work within the authorized task should continue without
repeated confirmation. Report the result, verification, limits and selectable next
steps. AI_HANDOFF.md covers source boundaries and continuation commands.
