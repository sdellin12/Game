# Digimon Card Game references

Reference for component stacks, inherited abilities and DNA digivolution/assembly edge cases. Do not import its resource or orientation-reset rules.

## Start with
Basic evolution chains, inherited abilities, DNA digivolution examples and related official rulings; one approachable starter deck.

## Official starting points
- https://world.digimoncard.com/rule/

## Upload here
Save rules_YYYY-MM-DD.pdf/txt, cards.csv/json, decks.md, rulings.md and/or source-links.md in this folder. Include source, revision/date and card IDs. See ../README.md. No full dataset is required and none has been imported yet.
