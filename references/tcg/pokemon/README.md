# Pokémon TCG references

Reference for beginner-readable presentation, evolution, damage tracking and explicit weakness/resistance concepts. Its Energy, Prize and one-active-creature systems are separate.

## Start with
Basic/Stage1/Stage2 chain; simple attackers, recovery and damage prevention; an introductory deck; clear official card images/text/IDs.

## Official starting points
- https://play.pokemon.com/en-us/resources/rules/

## Upload here
Save rules_YYYY-MM-DD.pdf/txt, cards.csv/json, decks.md, rulings.md and/or source-links.md in this folder. Include source, revision/date and card IDs. See ../README.md. No full dataset is required and none has been imported yet.
