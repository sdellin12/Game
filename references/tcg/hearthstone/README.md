# Hearthstone references

Useful numeric/design comparison for attack/health bodies, persistent minion damage and an automatically growing resource economy. Its timing and targeting are not our rules.

## Start with
Simple low/mid/high-cost minions; neutral bodies; Taunt, Rush, Divine Shield, healing and resource growth examples; straightforward aggro and control decks. Official beginner/help links are fine if no complete downloadable rulebook exists.

## Official starting points
- https://hearthstone.blizzard.com/en-us/cards

## Upload here
Save rules_YYYY-MM-DD.pdf/txt, cards.csv/json, decks.md, rulings.md and/or source-links.md in this folder. Include source, revision/date and card IDs. See ../README.md. No full dataset is required and none has been imported yet.
