# Magic: The Gathering references

Primary reference for priority/responses, activated and triggered abilities, blockers, commander-like leaders and singleton construction.

## Start with
Cost1–6 plain creatures; aggressive and defensive bodies; counterspells; protection; tokens; transform/meld; one simple aggro and one defensive deck. Include a Commander rules reference separately, not as a replacement for general rules.

## Official starting points
- https://magic.wizards.com/en/rules

## Upload here
Save rules_YYYY-MM-DD.pdf/txt, cards.csv/json, decks.md, rulings.md and/or source-links.md in this folder. Include source, revision/date and card IDs. See ../README.md. No full dataset is required and none has been imported yet.
